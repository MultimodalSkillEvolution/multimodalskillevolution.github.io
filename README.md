# MUSE

Anonymous project page for **MUSE: Evolving Grounded Multimodal Skills for Cross-Episode Agent Improvement**.

This repository contains the static website and anonymous manuscript. It has no external scripts, fonts, analytics, or login requirement.

## Local preview

Run `python3 -m http.server 8000` in this directory and open `http://localhost:8000`.

## GitHub Pages

Target repository: `MultimodalSkillEvolution/multimodalskillevolution.github.io`.

Publish the root directory of the `main` branch. The `.nojekyll` file enables direct static-file deployment.

- `index.html`: page content
- `styles.css`: presentation
- `results-data.js`: paper-reported benchmark values
- `app.js`: result exploration and figure viewer
- `assets/`: paper figures, anonymous PDF, and CSV results
