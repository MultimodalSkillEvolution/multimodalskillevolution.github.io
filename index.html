Method & evaluation details

Build the library

Independently solved, error-free seed trajectories with correct answers are distilled into structured profiles: applicability, visual hints, reasoning hints, verifier hints, and retrieval descriptors.

Reuse on new tasks

The main setting uses 20 labeled seeds, 20 skill profiles, and 20 offline rounds. The library is frozen before evaluation. Reuse is checked against the current image, without evaluation labels or model parameter updates.

Results

Five backbones on four benchmarks; two 8B models on M3CoT.
